# Course Prequisite Backend Project

This is a UMBC Software Engineering semester long project developed by four UMBC Students. In cooperation with two other groups our goal is too build a webpage for course signups for a college. Our selected college was JHU, John Hopkins University, as their API is well built and had good documentation.

Our main stakeholders are Professor Micheal Miller and the students of JHU. 

Our first sprint has wrapped up on 10/14 for our first sprint we completed

1) A design and implementation of a database
2) Request logic from the JHU API
3) Development of a team API to pull from database and package as JSON
4) Test cases
5) Plans for an is_elgible and available_classes
